# ggsegMelbourne: Melbourne Subcortex Atlas for the 'ggsegverse' Ecosystem

Melbourne Subcortex Atlas (Tian et al. 2020) for the 'ggseg' ecosystem.
Provides the four hierarchical parcellation scales as 'ggseg_atlas'
objects with 2D polygon geometry and 3D mesh data for use with 'ggseg'
and 'ggseg3d'.
